# 2026-09-24

**Goal**  Build the dynamic panel AR(1) Monte Carlo of `SPEC.md` end to end:
          DGP, three estimators, the T grid, the four deliverables, and the
          spec-check skill that audits the repo against the spec.

**Did**   Whole project from an empty directory plus the spec, in four commits.
          - `src/sim/` — `config` (every parameter, once), `analytics` (the
            plims), `dgp`, `estimators`, `runner`, `summarize`, `figures`,
            `tables`, `report`, `check`.
          - Estimators as closed-form ratios of sums, clustered by individual.
            The within estimator demeans y and its lag separately, which the
            tests check equals LSDV exactly.
          - 47 tests: the spec's own benchmark numbers, equivalence with the
            textbook least-squares fits and their cluster sandwiches, and the
            gate SPEC.md asks for — at N = 10^6, T = 10 every estimator lands
            within 0.005 of its plim.
          - `Makefile` with one file target per design cell, so `make -j`
            parallelises the grid and reruns only what is stale; the grid is
            Make variables the HPC run overrides (`make sim R=1000 N=5000`).
          - Every parquet stamps the SHA-256 of `SPEC.md` and the git commit;
            `make check` verifies both plus `make -q all`.
          - `.claude/skills/spec-check/SKILL.md` — three checks in order:
            spec internally consistent, code matches spec, outputs current.
          - Results match the analytical plims in all 30 cells, largest gap
            0.013: pooled 0.700 / 0.982, FD −0.150 both, within 0.080 → 0.664.
            Coverage 0.98 for pooled-in-M0, 0.00 for the five biased cells.
          - One-page HTML summary (`make report`), also published as a private
            artifact.
